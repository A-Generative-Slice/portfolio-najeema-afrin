## 📖 Executive Summary

The **FDNA (Fashion Design & Needlework Artistry)** ecosystem is a bespoke digital atelier built for **Najeema Afrin**, an accomplished fashion and costume designer specializing in intricate bridal hand embroidery and contemporary structural garments.

Created by **A Generative Slice (AGS)**, the platform transitions traditional physical fashion portfolios into a responsive, editorial-grade digital presentation system that functions both as a fluid web portfolio on mobile devices and an interactive 16:9 presentation deck for fashion houses, casting directors, and luxury couture recruiters.

---

## 🌟 Curated Collections & Features

### 1. Digital Atelier (Homepage)
A minimalist, high-fashion gateway featuring Najeema's curriculum vitae, design philosophy, technical competencies, and entry portals to curated collections.

### 2. Victorian Glam Collection (`victorian-glam.html`)
An editorial deep-dive exploring historical corsetry, dramatic silhouettes, structured bodices, and contemporary fabric manipulations.

### 3. Hand Embroidery Collection (`hand-embroidery.html`)
High-resolution macro showcases of artisanal zardozi, aari needlework, beaded embellishments, and traditional South Asian bridal craftsmanship.

### 4. Interactive Slide Mode
A bespoke presentation controller that enables seamless keyboard and touch navigation across collection items in a slide-by-slide format optimized for recruiters.

## 🎨 Design Philosophy & Aesthetic Palette

- **Deep Maroon (`#4A0E17`)**: Symbolizing heritage luxury and bridal depth.
- **Antique Gold (`#D4AF37`)**: Accenting intricate needlework and regal embellishments.
- **Ivory Cream (`#FDFBF7`)**: Providing an uncluttered, museum-grade backdrop for textile textures.
- **Typography**: Clean serif editorial titles paired with legible humanist sans-serif descriptions.

## 🚀 Running Locally

Because this project is built using native, dependency-free web technologies (Vanilla HTML5, CSS3, and ES6 JavaScript), it requires no build steps or bundlers.

```bash
# 1. Clone repository
git clone https://github.com/A-Generative-Slice/FDNA.git
cd FDNA

# 2. Serve locally using any static HTTP server:
npx serve .
# or
python -m http.server 3000
```

Open `http://localhost:3000` in any modern web browser.
